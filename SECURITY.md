# Security

If you find a way the app could harm a controller, a dongle or a Mac, or expose a user's data, please report it
privately rather than in a public issue: use **Report a vulnerability** on the repository's Security tab, or write to
github@arithon.org. Say which version of the app you used and how to reproduce the problem.

Only the latest release is supported. The checks the app makes before and while it writes are described in
[SAFEGUARDS.md](SAFEGUARDS.md).
